# 038_CACHE_SYSTEM.md - نظام الذاكرة المؤقتة التخزينية (Caching Engine)

## 1. Purpose (الهدف)
تأسيس وتوثيق طبقات الذاكرة المؤقتة لتقليل زمن الاستجابة ومنع تكرار استعلامات قواعد البيانات أو طلبات API المكلفة.

## 2. Responsibilities (المسؤوليات)
* التخزين المؤقت لنتائج الاستعلامات الشائعة للبحث النصي المتكرر.
* الاحتفاظ بمتجهات الاستعلامات الحديثة لتفادي التوليد المكرر لها.
* سياسة إخلاء الذاكرة المؤقتة القائمة على الأكثر قدماً واستخداماً (Least Recently Used - LRU).

## 3. Dependencies (الاعتماديات)
* يرتبط بـ `013_PERFORMANCE.md` و `022_SEARCH_ENGINE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **In-Memory LRU Cache**: الذاكرة المؤقتة التكتيكية سريعة الوصول للنصوص.
* **Persistent Disk Cache**: الذاكرة التخزينية الثابتة للنماذج والمتجهات.

## 5. Future Expansion (التوسع المستقبلي)
* دمج محرك Redis محلي خفيف في التوزيعات المؤسسية الكبيرة.

## 6. Risks (المخاطر)
* تقديم نتائج قديمة أو غير محدثة (Stale Data) إذا لم يتم تفريغ الذاكرة المؤقتة عند تعديل البيانات.

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب ربط مفاتيح الكاش بالتسلسل الهاشي لضمان مطابقة النتائج مع الحالة المحدثة دائماً.
