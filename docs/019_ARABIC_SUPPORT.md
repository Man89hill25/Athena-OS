# 019_ARABIC_SUPPORT.md - دعم اللغة العربية والخطوط والتحليل اللغوي

## 1. Purpose (الهدف)
تأسيس البنية التحتية البرمجية لدعم اللغة العربية كخيار رئيسي أول (Arabic-First) يشمل المعالجة النصية والتحليل اللغوي وإزالة التشكيل والعرض المريح.

## 2. Responsibilities (المسؤوليات)
* تطبيق محرك توحيد الحروف (Arabic Normalizer Engine) الذي يعالج الألف بجميع أشكالها (أ، إ، آ -> ا) والياء/الألف المقصورة والتاء المربوطة.
* معالجة التشكيل (حذف التشكيل للبحث الشامل، والحفاظ عليه للعرض الأكاديمي والتحقيق).
* معالجة الاتجاهية الثنائية (Bi-Directional BiDi Handling) للنصوص الهجينة التي تحتوي أرقاماً ورموزاً أجنبية.

## 3. Dependencies (الاعتماديات)
* يخدم محركات البحث `022_SEARCH_ENGINE.md` وقواعد البيانات `006_DATABASE_ARCHITECTURE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **Arabic Normalizer Module**:
  ```typescript
  export function normalizeArabicText(text: string): string {
    return text
      .replace(/[\u064B-\u0652]/g, "") // إزالة التشكيل
      .replace(/[أإآ]/g, "ا")
      .replace(/ى/g, "ي")
      .replace(/ة/g, "ه")
      .trim();
  }
  ```
* **Morphological Root Extractor**: المكون المخصص للربط بالجذور الثلاثية والرباعية للكلمات العربية.

## 5. Future Expansion (التوسع المستقبلي)
* دعم خطوط التراث النادرة ومعالجة الاختصارات التراثية (مثل: "رض"، "رح"، "طـ").

## 6. Risks (المخاطر)
* خطأ إزالة التشكيل في النصوص الحساسة التي يتغير معناها بتغير الحركات (مثل: قَبَل وقُبِل).

## 7. Engineering Notes (الملاحظات الهندسية)
* يتم الاحتفاظ دائماً بالنص الأصلي بالتشكيل في قاعدة البيانات مع إنشاء حقل موازي مخصص للبحث النصي المجرد.
