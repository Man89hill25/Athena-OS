# 005_FOLDER_STRUCTURE.md - هيكلية المجلدات والملفات

## 1. Purpose (الهدف)
تعريف الهيكل التنظيمي الشامل لمجلدات وملفات مشروع Athena OS لضمان الاتساق البرمجي، وسهولة الوصول، ومنع التداخل بين المكونات.

## 2. Responsibilities (المسؤوليات)
* توضيح أماكن حفظ الوثائق (`/docs`), المكونات (`/src/components`), الخدمات (`/src/services`), والمحركات Backend (`/server`).
* تنظيم تقسيم وحدات النواة الأكاديمية والذكاء الاصطناعي.

## 3. Dependencies (الاعتماديات)
* يعتمد على `003_ARCHITECTURE.md` و `004_TECH_STACK.md`.

## 4. Internal Structure (الهيكل الداخلي)
```
/
├── docs/                      # جميع وثائق المخطط الهندسي (000-049)
├── src/                       # الواجهة الأمامية والمنطق الخفيف
│   ├── assets/                # الصور والخطوط
│   ├── components/            # مكونات React المجمعة الموديلية
│   │   ├── layout/            # الهياكل والإطارات الموحدة
│   │   ├── docs/              # مستعرض مستندات المخطط الهندسي
│   │   ├── library/           # مدير المكتبات والكتب
│   │   ├── search/            # محرك البحث الهجين والبحث المتقدم
│   │   ├── timeline/          # محرك الخط الزمني التاريخي
│   │   ├── graph/             # محرك الرسم البياني المعرفي
│   │   └── ai/                # واجهات الوكلاء واستدلال Gemini
│   ├── hooks/                 # الخطافات المخصصة (Custom Hooks)
│   ├── types/                 # تعريفات الأنواع الموحدة
│   ├── utils/                 # الوظائف المساعدة والـ Parsers
│   ├── App.tsx                # المكون الرئيسي للمركز الهندي للتطوير
│   └── main.tsx               # مدخل التطبيق
├── server/                    # خدمات الخادم الخلفي والنواة
│   ├── db/                    # محركات SQLite و Vector Store
│   ├── ai/                    # تكامل Gemini SDK ووظائف RAG
│   └── ocr/                   # محرك معالجة النصوص والـ OCR
├── metadata.json              # بيانات التطبيق والقدرات
├── package.json               # التبعيات والسكربتات
└── tsconfig.json              # إعدادات المترجم
```

## 5. Future Expansion (التوسع المستقبلي)
* إضافة مجلد `/desktop` لتجميع تعليمات Tauri/Rust الخاصة بالتطبيق الذاتي.
* إضافة مجلد `/plugins` لاستيعاب الإضافات الخارجية المصممة من قبل المستخدمين.

## 6. Risks (المخاطر)
* خلط منطق الأعمال (Business Logic) داخل مجلدات الواجهة العرضية (`/components`).

## 7. Engineering Notes (الملاحظات الهندسية)
* يمنع إنشاء أي ملف خارج هذا الهيكل المعياري المعرف بدقة.
