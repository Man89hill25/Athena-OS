# 039_MEMORY_SYSTEM.md - نظام الذاكرة الممتدة للنموذج والباحث

## 1. Purpose (الهدف)
تصميم وتوثيق نظام الذاكرة العميقة والمستمرة المخصص للوكلاء الأذكياء ومساعد البحث للحفاظ على السياق الأكاديمي عبر الجلسات الممتدة.

## 2. Responsibilities (المسؤوليات)
* حفظ تفضيلات الباحث، منهج أبحاثه، والموضوعات النشطة التي يعكف على دراستها.
* ضغط واستعراض ملخصات الجلسات السابقة وتأطيرها بداخل النافذة السياقية المتاحة لـ Gemini.
* منع التضارب والتناقض الذاتي للنماذج عبر استدعاء الحقائق الثابتة المسجلة في بروفايل الباحث.

## 3. Dependencies (الاعتماديات)
* يغذي `007_AI_ARCHITECTURE.md` و `027_AI_AGENTS.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **Episodic Memory Store**: ذاكرة الجلسات اللحظية وسياق الحوار القريب.
* **Semantic Long-Term Memory**: ذاكرة التفضيلات العلمية والقواعد الدائمة المستخرجة من سلوك الباحث.

## 5. Future Expansion (التوسع المستقبلي)
* تمكين المزامنة الذاتية المعزولة بين ذاكرات الأجهزة الشخصية للباحث.

## 6. Risks (المخاطر)
* تضخم حجم الذاكرة السياقية مما قد يرفع تكلفة ومُهل الاستجابة.

## 7. Engineering Notes (الملاحظات الهندسية)
* يتم تطبيق خوارزمية التلخيص المجدول لضغط السياق التاريخي إلى 10% من حجمه الأصلي مع الحفاظ على الكيانات.
