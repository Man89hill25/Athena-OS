# 049_DECISION_LOG.md - سجل القرارات المعمارية والتصميمية (ADR)

## 1. Purpose (الهدف)
توثيق كافة القرارات الهندسية والمعمارية الجوهرية (Architecture Decision Records - ADR) التي تم اتخاذها أثناء تصميم Athena OS مع بيان الأسباب والبدائل المرفوضة والنتائج.

## 2. Responsibilities (المسؤوليات)
* تتبع تاريخ القرارات المعمارية الحرجة والعلل الهندسية خلفها.
* ضمان عدم إعادة مناقشة أو نقض القرارات المحسومة بدون أسباب علمية جديدة.

## 3. Dependencies (الاعتماديات)
* يغطي ويحمي القرارات المتخذة في المستندات من `000_MASTER_PLAN.md` إلى `048_GLOSSARY.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **ADR-001: اعتماد اللغة العربية كخيار رئيسي (Arabic-First Principle)**
  * *القرار*: جعل الواجهة، السجلات، وتجربة القراءة مبنية بأسلوب RTL وبأعلى مقاييس الجمالية الأكاديمية العربية.
  * *السبب*: تقديم أفضل منصة معرفية للباحثين في التراث والعلوم الشرقية والأكاديمية.
* **ADR-002: اعتماد SQLite3 FTS5 + Vector Embeddings للبحث الهجين**
  * *القرار*: عدم الاعتماد الحصري على المتجهات أو البحث النصي فقط، بل الدمج بينهما عبر RRF.
  * *السبب*: ضمان السرعة الفائقة والوصول والدقة العالية للمصطلحات التراثية المحددة.
* **ADR-003: عزل واجهات Gemini API في خادم خلفي مستقل**
  * *القرار*: تنفيذ كافة طلبات الاستدلال عبر Express API وتجنب الكشف المباشر لمفاتيح API في العميل.
  * *السبب*: الامتثال لأعلى معايير الأمان وحماية الأسرار وتوفير معالجة وسيطة دقيقة.
* **ADR-004: التبويب التفاعلي والقراءة المتعددة في الواجهة**
  * *القرار*: دعم فتح وثائق متعددة بأسلوب التبويبات مع وضع القراءة المريح وتوزيع الكروت الموزونة.
  * *السبب*: تمكين الباحث من المقارنة والدراسة العميقة دون التشتت بين الشاشات.

## 5. Future Expansion (التوسع المستقبلي)
* إضافة سجلات جديدة لكل قرار معمارى جوهري يتم اتخاذه مستقبلاً.

## 6. Risks (المخاطر)
* اتخاذ قرارات بدون توثيقها مما يؤدي إلى فقدان المبررات الهندسية على المدى الطويل.

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب إدراج كل قرار بنسق قياسي يحتوي: (العنوان، الموقف، السياق، القرار المتخذ، والنتائج المترتبة).
