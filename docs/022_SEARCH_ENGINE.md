# 022_SEARCH_ENGINE.md - محرك البحث المتقدم والبحث الهجين (Hybrid Search)

## 1. Purpose (الهدف)
بناء محرك البحث الرئيسي لنظام Athena OS الذي يدمج بين البحث النصي الحرفي (FTS5)، البحث باللواصق والجذور، والبحث الدلالي بالمتجهات (Dense Vector Search).

## 2. Responsibilities (المسؤوليات)
* تنقيح وتجريد الاستعلام البحثي المائل باللغة العربية وتحليله إلى مكوناته المفتاحية والدلالية.
* البحث المتوازي عبر جداول FTS5 وفهارس المتجهات وتجميع النتائج بناءً على معادلة ترتيب هجينة (Reciprocal Rank Fusion - RRF).
* إبراز الكلمات الافتتاحية (Highlighting) وتحديد موقع النتيجة بالصفحة والجزء.

## 3. Dependencies (الاعتماديات)
* ينسق مع `006_DATABASE_ARCHITECTURE.md`, `019_ARABIC_SUPPORT.md`, و `023_VECTOR_DATABASE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **Query Preprocessor**: معالج الجمل وتجريد التشكيل والتفتيت اللغوي.
* **FTS Search Stream**: البحث النصي في SQLite3 FTS5 عبر الاستعلام الحرفي مع التفتيت العائلي.
* **Vector Similarity Stream**: حساب المسافة الجيبية (Cosine Distance) بين متجهات الاستعلام والمتجهات المخزنة.
* **RRF Rank Fusion Engine**: الخالط الذكي للنتائج:
  $$Score(d) = \frac{1}{60 + r_{FTS}(d)} + \frac{1}{60 + r_{Vector}(d)}$$

## 5. Future Expansion (التوسع المستقبلي)
* دعم الاستعلام الصوتي واسترجاع المقولات بأساليب إعادة الصياغة البلاغية.

## 6. Risks (المخاطر)
* تباطؤ دمج النتائج عند وجود آلاف المطابقات من المسارين بنفس الوقت.

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب أن تعمل عملية البحث في مسار خلفي مستقل لمنع تجميد الواجهة أثناء الكتابة.
