# 023_VECTOR_DATABASE.md - قاعدة بيانات المتجهات الرياضية (Vector Storage)

## 1. Purpose (الهدف)
توثيق معمارية وآليات تخزين واسترجاع المتجهات الرياضية عالية الأبعاد (Embeddings) المسؤولة عن فهم التقارب الدلالي بين المفاهيم والكتب.

## 2. Responsibilities (المسؤوليات)
* توليد المتجهات بواسطة نماذج Google Text Embeddings عالية الأداء عبر API.
* التخزين المحلي للمتجهات بأبعاد 768 / 1536 أبعاد بآلية فائقة السرعة.
* دعم البحث السريع الجار الأقرب (Approximate Nearest Neighbor - ANN).

## 3. Dependencies (الاعتماديات)
* يرتبط بـ `008_RAG_ARCHITECTURE.md` و `022_SEARCH_ENGINE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **Embedding Generator**: المكون الذي يطلب التضمين الرياضي للنصوص العربية المحضرة.
* **Vector Storage Engine**: محرك التخزين الفعال الذي يحفظ المتجهات محلياً ويربط كل متجه بـ `page_id` و `book_id`.

## 5. Future Expansion (التوسع المستقبلي)
* الضغط الكمي للمتجهات (Vector Quantization - PQ/SQ8) لتقليل حجم الذاكرة المستهلكة بنسبة 75%.

## 6. Risks (المخاطر)
* تضخم حجم ملف قواعد المتجهات عند تخزين ملايين الصفحات.

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب أن يتم إجراء عملية توليد المتجهات في مجموعات (Batch Operations) لتفادي التأخير ومراعاة حدود API.
