# 009_UI_UX_GUIDELINES.md - معايير واجهة وتجربة المستخدم

## 1. Purpose (الهدف)
وضع المبادئ والإرشادات البصرية والوظيفية المصممة لتقديم تجربة واجهة مستخدم عربية أكاديمية فاخرة، مريحة للعين، وداعمة للتركيز العميق في القراءة والبحث.

## 2. Responsibilities (المسؤوليات)
* تطبيق اتجاه الواجهة الكامل من اليمين إلى اليسار (RTL System) بشكل أصيل ونقي.
* تحديد نظام التباين والطباعة والألوان المريحة للأعين في جلسات القراءة الطويلة.
* التخلص التام من النماذج المكررة والمعتادة للذكاء الاصطناعي (Anti-Slop Guidelines).

## 3. Dependencies (الاعتماديات)
* يستخدم Tailwind CSS v4 مع المكونات الجمالية وأيقونات Lucide React وحركات Motion.

## 4. Internal Structure (الهيكل الداخلي)
* **Color Palette (لوحة الألوان الأكاديمية)**:
  * الخلفية العميقة: ألوان دافئة غير صارخة (Warm Off-White `#FBF9F5` / Slate Dark `#0F172A`).
  * الألوان العميقة المميزة: الأخضر الأكاديمي الزيتوني، الأزرق الحبري العتيق، والذهب العتيق.
* **Typography (الطباعة)**: خطوط عربية واضحة ومقروءة بدقة عالية (Amiri / Noto Naskh / Cairo) بنسب رياضة مريحة.
* **Interactions**: انتقالات ناعمة خفيفة الحركة عبر Motion دون إبطاء للتجربة.

## 5. Future Expansion (التوسع المستقبلي)
* دعم الثيمات المخصصة للباحثين (مثال: نمط المخطوطات القديمة، نمط التحقيق، والنمط الليلي الفائق).
* تخصيص أحجام الخطوط والتسلسلات الهرمية وتغيير المسافات بين السطور حسب رغبة القارئ.

## 6. Risks (المخاطر)
* اختلال تنسيق الجداول والرموز الأجنبية المدمجة داخل النص العربي (BiDi Directionality Mix).

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب إضافة الخاصية `dir="rtl"` بشكل كلي مع التأكد من عدم استخدام التموضع الصلب (left/right) بل الاستحواذ اللوجيستي (start/end).
