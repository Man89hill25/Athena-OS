# 024_SQL_DATABASE.md - قاعدة البيانات العلاقاتية والتنفيذ المباشر (Relational Engine)

## 1. Purpose (الهدف)
توثيق استخدام وتكامل قاعدة البيانات العلاقاتية SQLite كقاعدة أساسية وحيدة لتخزين الهياكل والفهارس والبيانات المترابطة محلياً داخل Athena OS.

## 2. Responsibilities (المسؤوليات)
* ضمان اتساق واستقرارية المعاملات عبر مبادئ ACID (Atomicity, Consistency, Isolation, Durability).
* تحسين أداء الفهارس الإضافية (Indexes) لتسريع عمليات القراءة على جداول الكتب والأحداث.
* التحديث التلقائي للأنماط الهيكلية (Database Migrations) دون الحاجة لإعادة إعادة الفهرسة من الصفر.

## 3. Dependencies (الاعتماديات)
* يخدم كافة الطبقات التقنية ومستندات `006_DATABASE_ARCHITECTURE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **SQLite Connection Manager**: محرك الاتصال الموحد المتزن مع دعم وضع `WAL mode`.
* **Migration Scripts Directory**: مجلد البرامج التنفيذية للتعديل الهيكلي التراكمي السلس.

## 5. Future Expansion (التوسع المستقبلي)
* تمكين التناظر والاتصال المباشر مع محركات Postgres أو Cloud SQL عند الحاجة للعمل المؤسسي التشاركي.

## 6. Risks (المخاطر)
* قفل قاعدة البيانات (Database Locking Conflicts) أثناء محاولات الكتابة المتزامنة من مسارات متعددة.

## 7. Engineering Notes (الملاحظات الهندسية)
* يجب كتابة كافة الاستعلامات المعقدة مع مراعاة وجود فهارس تغطية مناسبة (`EXPLAIN QUERY PLAN`).
