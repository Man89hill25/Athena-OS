# 021_MARKDOWN_ENGINE.md - محرك معالجة وعرض Markdown الأكاديمي

## 1. Purpose (الهدف)
توفير بيئة عرض وتحرير متقدمة لدعم لغة التنسيق Markdown المخصصة للأكاديميين والباحثين مع دعم كامل لخصائص التحقيق والتوثيق المكتبي.

## 2. Responsibilities (المسؤوليات)
* دعم التوثيق الأكاديمي والمراجع وحواشي السطور (Footnotes & Footnote References).
* دعم الرياضيات والمعادلات عبر KaTeX والرسوم البيانية الهيكلية عبر Mermaid.
* ضمان المعالجة السريعة والآمنة للشفرات النصية وتجنب ثغرات XSS.

## 3. Dependencies (الاعتماديات)
* يعتمد على `react-markdown` والمحولات المخصصة في الواجهة الأمامية.

## 4. Internal Structure (الهيكل الداخلي)
* **Custom Parsers**: محولات التعرف على صياغة التوثيق مثل `[^1]` و `[اسم الكتاب، جX، صYY]`.
* **RTL Block Decorator**: المغلف التلقائي للنصوص لضمان بقاء الهياكل والرموز الرياضية في مسارها الصحيح.

## 5. Future Expansion (التوسع المستقبلي)
* إضافة خيار التصدير المباشر المنسق للأبحاث بصيغ PDF و DOCX المجهزة للطباعة.

## 6. Risks (المخاطر)
* تعارض الحواشي السفلية مع التصفح اللانهائي (Virtual Scrolling) عند القراءة.

## 7. Engineering Notes (الملاحظات الهندسية)
* يتم تطبيق التنقية الإجبارية (Sanitization) لكل نص مرمز لتجنب أي حقن برمجي غير آمن.
