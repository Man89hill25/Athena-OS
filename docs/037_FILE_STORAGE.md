# 037_FILE_STORAGE.md - نظام تخزين الملفات والمحفوظات

## 1. Purpose (الهدف)
توثيق آليات ونظم تخزين الملفات والمستندات والصور والمخطوطات والأصول بداخل البنية التحتية المحلية لنظام Athena OS.

## 2. Responsibilities (المسؤوليات)
* إدارة التخزين المنظم في مجلد البيانات المخصص للمستخدم (`/data` أو AppData).
* توليد وتتبع الهياكل الشجرية وحفظ الملفات بأسماء هاش فريدة للوقاية من التدافع.
* تنظيف الملفات المؤقتة والمسودات غير المكتملة بشكل دوري.

## 3. Dependencies (الاعتماديات)
* يخدم `030_LIBRARY_MANAGER.md` و `031_IMPORT_PIPELINE.md`.

## 4. Internal Structure (الهيكل الداخلي)
* **File Vault Directory**:
  ```
  /storage
  ├── /books/       # ملفات الكتب الأصلية
  ├── /thumbnails/  # أغلفة الكتب وصور المصغرات
  ├── /ocr_scans/   # الصور المعالجة تحت الفحص
  └── /exports/     # المخرجات الجاهزة للتنزيل
  ```

## 5. Future Expansion (التوسع المستقبلي)
* الضغط الذكي للملفات والصور النادرة دون المساس بدقة التفاصيل التراثية للخط.

## 6. Risks (المخاطر)
* امتلاء القرص الصلب عند استيراد مكتبات ضخمة بحجم مئات الجيجابايت.

## 7. Engineering Notes (الملاحظات الهندسية)
* يتم إحصاء وفحص المسافة المتاحة على القرص الصلب قبل البدء بأي عملية استيراد موسعة.
